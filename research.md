## Passive Patient Activity Monitoring using Federated Learning
**[Undergraduate Thesis]**
*September, 2022 - August, 2023*

**Supervisor:** Dr. Asaduzzaman, Professor, Dept. of CSE, CUET

* Developed and theoretically demonstrated a methodology that detects seven activities targeted towards patient monitoring using **Channel State Information (CSI)** data from existing WiFi infrastructure.
* Implemented a privacy-preserving **Federated Learning (FL)** framework with deep learning algorithms on CSI data from three distinct environments, enabling edge-based model training.
* Evaluated the feasibility of the edge-based FL approach against central server training.

## A Hybrid Semantic–Sequential Neural Architecture for Multi-label Toxic Comment Classification
*In Collaboration with Sourav Saha and K M Nafi Asib*

* Designed and evaluated a fusion model combining **Transformer-based models with Recurrent Neural Networks (RNNs)** for detecting toxic comments in the low-resource **Bengali language**.
* The model was improved by effectively capturing semantic and contextual nuances beyond surface-level lexical features, enhancing detection accuracy.
